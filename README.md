# HaadinGlobal — Results-Driven Digital Marketing Agency

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 📦 Production Build

```bash
npm run build
npm start
```

## 🌐 Deploy to Vercel

1. Push to GitHub
2. Connect repo to Vercel
3. Deploy (zero config needed)

## ⚙️ Setup Checklist

1. **Formspree** — Replace `YOUR_FORMSPREE_ID` in `src/data/siteConfig.ts`
   - Sign up at formspree.io → create form → copy ID
   
2. **Google Search Console** — Replace `YOUR_GOOGLE_SEARCH_CONSOLE_ID` in `src/app/layout.tsx`

3. **Domain** — Update `SITE.url` in `src/data/siteConfig.ts`

## 🔧 Tech Stack

- **Next.js 14** (App Router)
- **React 18** + TypeScript
- **Tailwind CSS** + custom animations
- **Framer Motion** — scroll animations, parallax, cinematic transitions
- **Pure CSS 3D Globe** — no Three.js (Vercel-optimized)
- **EN/AR** bilingual with auto IP-based detection

## 📁 Project Structure

```
src/
├── app/           # Next.js App Router pages
├── components/
│   ├── home/      # Hero, Services, About, Testimonials, etc.
│   ├── layout/    # Navbar, Footer
│   ├── pricing/   # PricingCards, PricingCalculator
│   ├── contact/   # ContactForm
│   └── providers/ # LanguageProvider (EN/AR)
├── data/          # Services, testimonials, blog, translations
├── styles/        # globals.css
└── utils/         # Helper functions
```
